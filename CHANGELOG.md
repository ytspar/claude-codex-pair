# Changelog

## v0.1.0 — March 26, 2026

Initial release.

### Features
- Native macOS app (SwiftUI + SwiftTerm)
- Split-pane: Claude Code terminal (left) + Codex review panel (right)
- Codex completion gate via Claude Code Stop hook
- Direct PTY input injection (no clipboard, no System Events)
- Multi-session tabs with Cmd+1-9 switching
- Project picker with recent projects and search
- Auth check for Claude + Codex (API key and subscription)
- Theme toggle: Devbar emerald / Ghostty user config (Cmd+T)
- Departure Mono typography
- Scratchpad for drafting prompts
- read_screen / send_key / send_input IPC
- Shell integration (ZDOTDIR trick)
- Shared rules.md for Claude↔Codex alignment
- GhosttyKit xcframework built (optional Metal rendering)
- About window with version + attribution
